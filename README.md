# Hub Kit

The shared base for all of Simon's study hubs.

- [GUIDE.md](GUIDE.md): how the hubs work and how to make a new one, step by step.
- [OUTLINE.md](OUTLINE.md): every hub, its course, live site, repo and extras.
- [base/](base/): the starter (newest engine with an example course). Copy it to start a new hub.
- [shell/](shell/) + `node tools/build.js all`: the shared hub shell for the family hubs (`study-hub`, `margo-hub`), listed in [hubs.json](hubs.json). See GUIDE.md, section 7.

Landing page with links to every hub: https://mrsimonm.github.io/hub-kit/
